# Package index

## Main functions

The main agent constructor, plus the building blocks for a commons
agent.

- [`commons()`](https://posit-dev.github.io/commons/reference/commons.md)
  : Create a commons agent
- [`data_source()`](https://posit-dev.github.io/commons/reference/data_source.md)
  : Create a data source
- [`semantic_layer()`](https://posit-dev.github.io/commons/reference/semantic_layer.md)
  : Create a semantic layer
- [`measure()`](https://posit-dev.github.io/commons/reference/measure.md)
  : Create a measure
- [`context_layer()`](https://posit-dev.github.io/commons/reference/context_layer.md)
  : Create a context layer

## Shiny UI and server

Put a commons agent inside of an interactive chat app.

- [`commons_app()`](https://posit-dev.github.io/commons/reference/commons_app.md)
  [`commons_ui()`](https://posit-dev.github.io/commons/reference/commons_app.md)
  [`commons_server()`](https://posit-dev.github.io/commons/reference/commons_app.md)
  : Shiny chat UI and server for commons agents

## Trajectories

Read and annotate conversation histories.

- [`trajectory_read()`](https://posit-dev.github.io/commons/reference/trajectory_read.md)
  : Read commons trajectories
- [`trajectory_review()`](https://posit-dev.github.io/commons/reference/trajectory_review.md)
  : Review commons trajectories
