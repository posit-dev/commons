# Package index

## Main functions

The main agent constructor, plus the building blocks for a commons
agent.

- [`commons()`](https://solid-adventure-ny1mpqy.pages.github.io/reference/commons.md)
  : Create a commons agent
- [`data_source()`](https://solid-adventure-ny1mpqy.pages.github.io/reference/data_source.md)
  : Create a data source
- [`semantic_layer()`](https://solid-adventure-ny1mpqy.pages.github.io/reference/semantic_layer.md)
  : Create a semantic layer
- [`context_layer()`](https://solid-adventure-ny1mpqy.pages.github.io/reference/context_layer.md)
  : Create a context layer

## Shiny UI and server

Put a commons agent inside of an interactive chat app.

- [`commons_app()`](https://solid-adventure-ny1mpqy.pages.github.io/reference/commons_app.md)
  [`commons_ui()`](https://solid-adventure-ny1mpqy.pages.github.io/reference/commons_app.md)
  [`commons_server()`](https://solid-adventure-ny1mpqy.pages.github.io/reference/commons_app.md)
  : Shiny chat UI and server for commons agents

## Trajectories

Read and annotate conversation histories.

- [`trajectory_read()`](https://solid-adventure-ny1mpqy.pages.github.io/reference/trajectory_read.md)
  : Read commons trajectories
- [`trajectory_review()`](https://solid-adventure-ny1mpqy.pages.github.io/reference/trajectory_review.md)
  : Review commons trajectories

## Miscellaneous

- [`list_tables()`](https://solid-adventure-ny1mpqy.pages.github.io/reference/list_tables.md)
  : List the tables an agent can query
- [`measure()`](https://solid-adventure-ny1mpqy.pages.github.io/reference/measure.md)
  : Create a measure
