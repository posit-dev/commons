Read README.Rmd to understand the goal of the project.

Treat the files in inst/resources as examples of thoughtfully executed instances of what we're trying to build a tool for.

The files in inst/tiles should be treated as an example potential use case for this package; the author of that tiles app might adopt this package to create such an agent.

inst/references contains various write-ups that may be useful here or there.

This package has not been widely adopted or publicly released; changes can be made without a deprecation cycle (or even reference to the way that it used to work)/
