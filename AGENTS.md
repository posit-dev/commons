This package has not been widely adopted or publicly released; changes can be made without a deprecation cycle (or even reference to the way that it used to work).

`commons` supports a table-level `definitions` field in `data-dict.yaml` for governed SQL expressions, but it is an extension rather than part of the published data-dict specification. It anticipates the still-open [data-dict definitions proposal](https://github.com/tidyverse/data-dict/issues/134). When working on this part of the implementation, see [commons #48](https://github.com/posit-dev/commons/pull/48) for the provisional implementation and [commons #40](https://github.com/posit-dev/commons/issues/40) for the broader interoperability direction.
